# 微信小程序对接

本文档描述微信小程序端对接 DraARL Server 的完整 API 和协议说明。

## 服务器地址

| 环境 | 地址 |
|------|------|
| 生产 | `https://ptt.4l2.cn` |
| API 前缀 | `/api` |
| WebSocket | `wss://ptt.4l2.cn/ws` |

## 1. 账号密码登录

### 请求

```
POST /api/auth/login
Content-Type: application/json
```

```json
{
  "username": "用户名或邮箱",
  "password": "密码",
  "captcha_id": "验证码ID",
  "captcha_code": "验证码"
}
```

> 注意：登录前需要先获取图形验证码 `GET /api/captcha`，返回 `{ captcha_id, captcha_image }`。验证码有效期 5 分钟。

### 响应

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGci...",
    "refresh_token": "xxx",
    "expires_in": 3600,
    "refresh_expires_in": 1209600,
    "user": {
      "id": 1,
      "username": "bg5hve",
      "callsign": "BG5HVE",
      "role": "user",
      "status": 1,
      "approval_status": 1
    }
  }
}
```

### 小程序代码示例

```javascript
// 封装请求
const API_BASE = 'https://ptt.4l2.cn/api'

function request(url, method, data, token) {
  return new Promise((resolve, reject) => {
    wx.request({
      url: API_BASE + url,
      method: method,
      data: data,
      header: {
        'Content-Type': 'application/json',
        ...(token ? { 'Authorization': 'Bearer ' + token } : {})
      },
      success: resolve,
      fail: reject
    })
  })
}

// 登录
async function login(username, password, captchaId, captchaCode) {
  const res = await request('/auth/login', 'POST', {
    username, password, captcha_id: captchaId, captcha_code: captchaCode
  })
  if (res.data.code === 200) {
    // 保存 token
    wx.setStorageSync('access_token', res.data.data.token)
    wx.setStorageSync('refresh_token', res.data.data.refresh_token)
    wx.setStorageSync('user_info', res.data.data.user)
  }
  return res.data
}
```

## 2. 微信绑定与快捷登录

### 2.1 账号密码登录后绑定微信

**前提**：用户已通过账号密码登录，持有有效 JWT token。

```
POST /api/sso/wechat-mini/bind
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "code": "wx.login返回的code"
}
```

**响应（成功）**：
```json
{ "code": 200, "message": "绑定成功", "data": { "bound": true } }
```

**响应（已绑定）**：
```json
{ "code": 400, "message": "已绑定微信号，请先解绑" }
```

**响应（openid被占用）**：
```json
{ "code": 409, "message": "该微信号已绑定其他账号" }
```

### 小程序代码示例

```javascript
async function bindWeChat() {
  const { code } = await wx.login()
  const token = wx.getStorageSync('access_token')
  const res = await request('/sso/wechat-mini/bind', 'POST', { code }, token)
  return res.data
}
```

### 2.2 微信快捷登录

绑定微信后，可直接通过 `wx.login` 的 code 登录，无需输入账号密码。

```
POST /api/auth/wechat-mini/login
Content-Type: application/json
```

```json
{
  "code": "wx.login返回的code"
}
```

**响应（成功）**：
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGci...",
    "refresh_token": "xxx",
    "expires_in": 3600,
    "refresh_expires_in": 1209600,
    "user": { "id": 1, "username": "bg5hve", "callsign": "BG5HVE" }
  }
}
```

**响应（未绑定）**：
```json
{ "code": 404, "message": "该微信号未绑定账号，请先使用账号密码登录后绑定" }
```

### 2.3 查询绑定状态

```
GET /api/sso/wechat-mini/status
Authorization: Bearer <token>
```

**响应**：
```json
{
  "code": 200,
  "message": "成功",
  "data": { "bound": true, "openid": "oXXXXXXXXXXXXX" }
}
```

### 2.4 解绑微信

```
DELETE /api/sso/wechat-mini/unbind
Authorization: Bearer <token>
```

**响应**：
```json
{ "code": 200, "message": "解绑成功" }
```

## 3. WebSocket 连接

### 连接方式

小程序通过 `wx.connectSocket` 连接 WebSocket，使用 query parameter 传递 JWT token：

```javascript
const token = wx.getStorageSync('access_token')
const ws = wx.connectSocket({
  url: `wss://ptt.4l2.cn/ws?token=${token}`,
  header: { 'content-type': 'application/octet-stream' }
})
```

### 连接状态

| 事件 | 说明 |
|------|------|
| `onOpen` | 连接成功，开始发送心跳包 |
| `onMessage` | 收到二进制数据包，需解析 DraARLv1 协议 |
| `onClose` | 连接关闭，code 1008/1013 表示冲突 |
| `onError` | 连接错误 |

### 心跳

连接建立后，需每隔 30 秒发送一次心跳包保持在线。心跳包使用 DraARLv1 协议 Type=2。

## 4. DraARLv1 协议

### 4.1 头部结构（90 字节）

```
偏移  长度  字段            类型      说明
0     4    Version         char[4]   固定 "DraA"
4     2    Length          uint16 BE 整包长度（含头部和数据）
6     32   Username        char[32]  用户名（\x00 填充）
38    10   DevicePassword  char[10]  设备密码（JWT 认证留空）
48    1    Type            uint8     数据包类型
49    1    DevModel        uint8     设备型号（小程序=100）
50    1    SSID            uint8     设备子号（小程序=100）
51    3    DMRID           uint24 BE DMR ID（可留0）
54    32   CallSign        char[32]  呼号（\x00 填充）
86    4    Reserved        byte[4]   保留
90    ...  DATA            bytes     数据区
```

### 4.2 数据包类型

| Type | 值 | 说明 |
|------|-----|------|
| JWT_AUTH | 1 | JWT 认证包 |
| HEARTBEAT | 2 | 心跳包 |
| CONFIG | 3 | 设备配置 |
| TEXT_MESSAGE | 4 | 文本消息 |
| OPUS_16K | 5 | Opus 16K 语音（浏览器发送/接收） |
| PCM_16K | 6 | PCM 16K 语音（小程序发送） |

### 4.3 小程序 ArrayBuffer 编解码

```javascript
const HEADER_SIZE = 90
const DRAARL_VERSION = 'DraA'

// 字符串编码为定长字节数组
function encodeString(str, length) {
  const buf = new ArrayBuffer(length)
  const view = new Uint8Array(buf)
  const encoded = new TextEncoder().encode(str)
  view.set(encoded.slice(0, length))
  return view
}

// 构建心跳包
function buildHeartbeatPacket(username, callsign) {
  const buf = new ArrayBuffer(HEADER_SIZE)
  const view = new DataView(buf)
  const bytes = new Uint8Array(buf)

  // Version
  bytes.set(new TextEncoder().encode(DRAARL_VERSION), 0)
  // Length
  view.setUint16(4, HEADER_SIZE, false) // big-endian
  // Username
  bytes.set(encodeString(username, 32), 6)
  // Type = 2 (Heartbeat)
  bytes[48] = 2
  // DevModel = 100 (WeChat Mini)
  bytes[49] = 100
  // SSID = 100
  bytes[50] = 100
  // CallSign
  bytes.set(encodeString(callsign, 32), 54)

  return buf
}

// 构建语音包 (PCM)
function buildVoicePacket(username, callsign, pcmData) {
  const buf = new ArrayBuffer(HEADER_SIZE + pcmData.byteLength)
  const view = new DataView(buf)
  const bytes = new Uint8Array(buf)

  bytes.set(new TextEncoder().encode(DRAARL_VERSION), 0)
  view.setUint16(4, HEADER_SIZE + pcmData.byteLength, false)
  bytes.set(encodeString(username, 32), 6)
  // Type = 6 (PCM_16K)
  bytes[48] = 6
  // DevModel = 100 (WeChat Mini)
  bytes[49] = 100
  // SSID = 100
  bytes[50] = 100
  bytes.set(encodeString(callsign, 32), 54)
  // PCM data
  bytes.set(new Uint8Array(pcmData), HEADER_SIZE)

  return buf
}

// 构建文本消息包
function buildTextPacket(username, callsign, message) {
  const msgBytes = new TextEncoder().encode(message)
  const buf = new ArrayBuffer(HEADER_SIZE + msgBytes.byteLength)
  const view = new DataView(buf)
  const bytes = new Uint8Array(buf)

  bytes.set(new TextEncoder().encode(DRAARL_VERSION), 0)
  view.setUint16(4, HEADER_SIZE + msgBytes.byteLength, false)
  bytes.set(encodeString(username, 32), 6)
  // Type = 4 (Text Message)
  bytes[48] = 4
  bytes[49] = 100
  bytes[50] = 100
  bytes.set(encodeString(callsign, 32), 54)
  bytes.set(msgBytes, HEADER_SIZE)

  return buf
}

// 解析收到的数据包
function decodePacket(data) {
  if (data.byteLength < HEADER_SIZE) return null
  const view = new DataView(data)
  const bytes = new Uint8Array(data)

  const version = String.fromCharCode(bytes[0], bytes[1], bytes[2], bytes[3])
  if (version !== DRAARL_VERSION) return null

  const length = view.getUint16(4, false)
  const type = bytes[48]
  const devModel = bytes[49]
  const ssid = bytes[50]
  const callsign = new TextDecoder().decode(bytes.slice(54, 86).filter(b => b !== 0))
  const packetData = bytes.slice(HEADER_SIZE)

  return { version, length, type, devModel, ssid, callsign, data: packetData }
}
```

## 5. PCM 语音录制与发送

### 5.1 录音配置

小程序使用 `wx.getRecorderManager()` 录制 PCM 格式音频：

```javascript
const recorderManager = wx.getRecorderManager()

// 录音参数
const recorderConfig = {
  sampleRate: 16000,       // 16kHz 采样率（必须）
  numberOfChannels: 1,     // 单声道（必须）
  encodeBitRate: 48000,    // 对 PCM 无效但需要设置
  format: 'PCM',           // PCM 格式
  frameSize: 1.875          // 每帧 ~1.875KB ≈ 60ms PCM (16000Hz × 2bytes × 0.06s = 1920B)
}

// PTT 按下开始录音
recorderManager.start(recorderConfig)

// PTT 松开停止录音
recorderManager.stop()

// 帧数据回调 - 每帧约 60ms PCM 数据
let pcmBuffer = []
recorderManager.onFrameRecorded((res) => {
  // res.frameBuffer 是 ArrayBuffer 格式的 PCM 数据
  // res.isLastFrame 标记最后一帧
  pcmBuffer.push(res.frameBuffer)

  // 累积 2 帧（~120ms）后发送
  if (pcmBuffer.length >= 2) {
    const merged = mergeArrayBuffers(pcmBuffer)
    const packet = buildVoicePacket(username, callsign, merged)
    wx.sendSocketMessage({ data: packet })
    pcmBuffer = []
  }
})

// 合并 ArrayBuffer
function mergeArrayBuffers(buffers) {
  const totalLength = buffers.reduce((sum, buf) => sum + buf.byteLength, 0)
  const result = new Uint8Array(totalLength)
  let offset = 0
  for (const buf of buffers) {
    result.set(new Uint8Array(buf), offset)
    offset += buf.byteLength
  }
  return result.buffer
}
```

### 5.2 PCM 数据要求

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样率 | 16000 Hz | 16kHz |
| 声道数 | 1 | 单声道 |
| 位深 | 16-bit | int16 LE |
| 帧时长 | 60ms | 1920 字节/帧 |
| 每包帧数 | 2 | 3840 字节/包 |

服务端收到 PCM 数据后会自动转码为 Opus 格式再转发给其他客户端，UDP 设备和浏览器收到的均为 Opus 包。

## 6. 语音接收与播放

### 6.1 接收 Opus 语音

服务端转发的语音包始终是 Type=5（Opus 16K）。小程序收到后需要解码 Opus → PCM → 播放。

> 小程序原生不支持 Opus 解码。推荐方案：
> 1. 使用 WASM 版 Opus 解码器（如 `opus-decoder` 编译为 WASM）
> 2. 或由服务端增加 Opus → PCM 转码（未来版本支持）

### 6.2 播放 PCM 音频

如果获得 PCM 数据，可使用 `WebAudio` 或写入临时文件后用 `InnerAudioContext` 播放：

```javascript
// 方案：将 PCM 写入临时文件，用 InnerAudioContext 播放
const fs = wx.getFileSystemManager()
const tempPath = `${wx.env.USER_DATA_PATH}/voice_${Date.now()}.pcm`

// 注意：InnerAudioContext 不直接支持 PCM 播放
// 需要添加 WAV 头或转为其他格式
// 推荐使用 WebAudio API（如果小程序支持）或 WASM 解码后播放
```

| 类型 | 域名 |

## 8. 完整连接流程

```
1. wx.login() → code
2. POST /api/auth/wechat-mini/login { code }
   ├── 成功 → 获取 token，进入步骤 4
   └── 404 未绑定 → 进入步骤 3

3. 账号密码登录 + 绑定微信
   ├── GET /api/captcha → 获取验证码
   ├── POST /api/auth/login → 获取 token
   ├── wx.login() → code
   └── POST /api/sso/wechat-mini/bind { code }

4. 连接 WebSocket
   └── wx.connectSocket('wss://ptt.4l2.cn/ws?token=xxx')

5. 心跳保活
   └── 每 30s 发送心跳包 (Type=2)

6. PTT 语音
   ├── 按下 → recorderManager.start() 开始录音
   ├── 录音帧 → 累积 2 帧 PCM → 发送语音包 (Type=6)
   └── 松开 → recorderManager.stop()

7. 接收语音
   └── onMessage → 解析 Type=5 Opus → 解码播放
```

## 9. 错误码

| HTTP 状态码 | 含义 |
|-------------|------|
| 200 | 成功 |
| 400 | 请求参数错误 / 已绑定微信 |
| 401 | 未认证 / 微信 code 无效 |
| 403 | 用户已被禁用 |
| 404 | 用户不存在 / 微信号未绑定 |
| 409 | 微信号已绑定其他账号 |
| 503 | 微信小程序功能未配置 |

## 10. 后端配置要求

在 `config.yaml` 中添加微信小程序配置：

```yaml
WeChat:
    AppID: "wxYOUR_APPID"        # 微信小程序 AppID
    AppSecret: "YOUR_APP_SECRET"  # 微信小程序 AppSecret
```

服务端需要安装 libopus 库以支持 PCM → Opus 转码：
- Ubuntu/Debian: `apt install libopus-dev`
- CentOS: `yum install opus-devel`
- macOS: `brew install opus`
- Windows: 安装 MSYS2 并通过 pacman 安装 opus

编译时需要启用 CGO：`CGO_ENABLED=1 go build`
