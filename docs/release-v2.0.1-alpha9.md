# DraARL v2.0.1-alpha9

虚拟互联组的自动播报支持三种策略：全部暂停、选择代表组、各自独立。
各自独立时，每个实体组的自动播报只发送到本组，各组可以同时播报；本组播报期间忽略其他组互联传入的语音，冲突音频不会排队补播。
保存策略后立即重新判断成员组播报权限，并更新已在线连接的通信域；不再允许的当前播报安全停止。

修复 Web 电台误过滤互联来源组语音的问题。跨组语音、文字消息和正在发言提示现在保留并显示来源用户名；取消接收频道时清理缓冲中的互联语音。
同步更新自动播报 API、数据字典和 OpenAPI 策略枚举，OpenAPI 版本自动读取根目录 `VERSION`。

本地前后端检查、生产构建通过；已通过 SSH 在 Ubuntu 虚拟机验证群组语音路由、独立播报并发隔离及 MySQL 策略切换，相关竞态检测通过。原生客户端未实测。

更新服务端并刷新 Web 页面即可使用，无需手工修改数据库。
提供 Linux AMD64／ARM64、Windows AMD64、macOS Intel／Apple Silicon 安装包及对应 SHA-256 校验文件。
