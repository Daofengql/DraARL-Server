# 07. 资源上传与站点配置

## 1. 通用上传（JWT）

### `POST /api/upload/file`

`multipart/form-data` 字段：

- `file`：文件
- `file_type`：`avatar` / `other` / 自定义

返回示例：

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "file_name": "avatar.jpg",
    "file_size": 53211,
    "file_type": "avatar",
    "minio_path": "uploads/avatar/2026/04/xxx.jpg",
    "file_url": "https://...",
    "thumbnail_url": "https://..."
  }
}
```

## 2. 操作证上传与查询（JWT）

### `POST /api/upload/operator-certificate`

`multipart/form-data` 字段：

- `callsign`（可选）
- `file`（可选，multipart 兼容路径）
- 或直传完成后：`object_key` + `upload_token` + `file_name`

推荐流程：`POST /api/storage/presign-put`（`file_type=operator_cert`）→ PUT 直传 → 本接口提交 `object_key` 和 `upload_token`。

说明：

- `callsign` 仅表示“申请中的新呼号”，不会在用户提交时直接写入 `users.callsign`。
- 只有管理员审批通过后，新呼号才会真正生效。
- 如果提交的 `callsign` 已被其他用户占用，接口返回 `409`。
- 操作证上限 20MB；支持图片与 PDF。

返回示例：

```json
{
  "code": 200,
  "message": "操作证信息已提交，请等待管理员审核",
  "data": {
    "id": 99,
    "callsign": "BG7NEW",
    "file_name": "cert.pdf",
    "file_size": 124312,
    "upload_time": "2026-04-05 16:11:00"
  }
}
```

### `GET /api/operator-certificate`

返回 `active_cert`（已通过）和 `pending_cert`（待审/拒绝最近一条）。
两类证书对象都会返回 `callsign` 字段，表示该证书对应的呼号。

## 3. 站点 Logo/Favicon（Admin）

### `POST /api/upload/logo`

`multipart/form-data`：`file`

### `POST /api/upload/favicon`

`multipart/form-data`：`file`

## 3.1 通用存储与直传（JWT）

### `POST /api/storage/presign-put`

申请直传凭证。body：

```json
{
  "file_type": "assets",
  "file_name": "package.zip",
  "size": 1048576,
  "content_type": "application/zip"
}
```

`file_type` 支持 `assets` | `firmware` | `operator_cert`。其中 `assets`、`firmware` 仅管理员可申请，`operator_cert` 绑定当前用户。object key **仅由服务端生成**。

返回示例（MinIO）：

```json
{
  "code": 200,
  "data": {
    "mode": "s3",
    "upload_url": "https://minio.example/...",
    "method": "PUT",
    "headers": { "Content-Type": "application/zip" },
    "object_key": "staging/assets/1/2026/07/xxx.zip",
    "upload_token": "signed-upload-grant",
    "expires_at": "2026-07-14T12:00:00Z",
    "max_size": 104857600,
    "content_type": "application/zip"
  }
}
```

local 驱动下 `mode` 为 `local`，`upload_url` 指向 `PUT /api/storage/put?token=...&key=...`（token 鉴权，无需 JWT）。
上传内容先进入 staging；complete 会校验申请人、类型、实际大小和有效期，再提升为新的不可变 final key。未完成且超过 24 小时的 staging 对象会自动清理。

### `PUT /api/storage/put`

local 驱动专用直传入口；校验 query 中的 `token` 与 `key` 后写入存储。

## 4. 资源中心（Admin）

### 管理端

- `GET /api/assets`（管理员列表，参数 `parent_id`）
- `POST /api/assets/folder`
- `POST /api/assets/upload`（`multipart/form-data`: `parent_id` + `file` + `name` + `remark`，兼容代理上传）
- `POST /api/assets/complete`（直传完成后落库）
- `PUT /api/assets/:id`
- `PUT /api/assets/:id/move`
- `POST /api/assets/:id/replace`
- `DELETE /api/assets/:id`

直传完整流程：`presign-put` → 浏览器 `PUT` 到 `upload_url` → `POST /api/assets/complete`：

```json
{
  "parent_id": 12,
  "name": "客户端安装包",
  "remark": "",
  "object_key": "staging/assets/1/2026/07/xxx.zip",
  "upload_token": "signed-upload-grant"
}
```

示例：创建文件夹

```json
{ "name": "客户端安装包", "parent_id": null, "remark": "发布目录" }
```

示例：移动资源

```json
{ "target_parent_id": 12 }
```

### 前台公开下载

- `GET /api/assets/tree`
- `GET /api/assets/folder/:id`
- `GET /api/assets/:id/download`

下载链接返回示例：

```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "name": "draarl-client.exe",
    "size": 51200321,
    "mime_type": "application/octet-stream",
    "download_url": "https://...presigned..."
  }
}
```

## 4.1 固件上传（Admin）

- `POST /api/firmware`：`multipart/form-data`（兼容代理上传）
- `POST /api/firmware/complete`：直传完成后落库，服务端重算 SHA-256

`complete` body 示例：

```json
{
  "dev_model": 1,
  "version": "1.2.3",
  "changelog": "修复连接",
  "object_key": "staging/firmware/1/2026/07/xxx.bin",
  "upload_token": "signed-upload-grant",
  "file_name": "firmware.bin"
}
```
