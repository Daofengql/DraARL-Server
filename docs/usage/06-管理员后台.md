# 06. 管理员后台

管理员用户可进入 `/admin` 后台。后台菜单包括：

- 系统数据
- 用户管理
- 设备管理
- 群组管理
- 通信记录
- 资源管理
- 站点配置

## 1. 系统数据

后台首页 `/admin/dashboard` 展示系统全局统计：

- 总设备数。
- 在线设备。
- 群组数量。
- 用户数量。
- 通信记录数。
- 通信总大小。
- 通信总时长。
- 通信趋势。

## 2. 用户管理

- 账号管理 `/admin/users`
- 用户审批 `/admin/approvals`
- 操作证审批 `/admin/certificate-approvals`

管理员可：

- 查询用户列表。
- 查看用户详情。
- 修改用户资料、角色、状态。

- 删除用户。
- 重置用户密码。
- 审批注册用户。

## 6. 客户端资源分发

后台导航把两个独立子系统归在“客户端资源分发”下：

- 通用资源 `/admin/client-resources`：先登记稳定资源身份，再创建 SemVer 草稿、上传 artifact、显式多选平台/架构组合并发布。安装包、模型、字库和词典使用同一套流程。
- 设备固件 `/admin/firmware`：继续按设备型号维护独立固件记录和 OTA 选择逻辑，不出现在通用资源 manifest。

通用 artifact 先浏览器直传 staging，后端流式计算 SHA-256 后提升为不可变对象。同一文件可绑定多个明确 target，但没有 `universal` 通配。已发布版本可进入编辑状态追加不冲突的 artifact，适合先发布 Android 再补充 Windows；已有 artifact 不可覆盖。删除版本会立即停止其 manifest 分发，并清理关联对象。资源页会显示当前管理员待完成的 staging 上传，可重新签发 complete 凭证继续提交；发布确认会展示 final key、大小、SHA-256 和目标范围。

“对象审计”入口只读扫描 `client-resources/` 和新固件 `firmware/` final 对象，统计未被数据库引用的对象以及数据库引用缺失的对象。它不会自动删除对象，清理策略需要单独人工确认。

相关 API：

| Method | Path | Auth | 说明 |
|---|---|---|---|
| GET / POST | `/api/client-resources` | Admin | 资源定义列表/创建。 |
| DELETE | `/api/client-resources/:resource_id` | Admin | 级联删除资源、全部版本、artifact、target 和对象文件。 |
| GET / POST | `/api/client-resources/:resource_id/releases` | Admin | 版本列表/创建草稿。 |
| POST | `/api/client-resources/:resource_id/releases/:release_id/artifacts/complete` | Admin | 完成 artifact 直传或追加到已发布版本。 |
| POST | `.../:release_id/publish` | Admin | 发布草稿。 |
| DELETE | `.../:release_id` | Admin | 删除资源版本及关联对象。 |
| GET | `/api/client-resources/staging` | Admin | 待完成上传列表。 |
| POST | `/api/client-resources/staging/retry` | Admin | 重签待完成上传凭证。 |
| GET | `/api/storage/audit` | Admin | 只读对象引用审计。 |
| GET | `/api/firmware` | Admin | 固件列表。 |
| POST | `/api/firmware/complete` | Admin | 完成固件直传。 |
| DELETE | `/api/firmware/:id` | Admin | 删除固件。 |

完整协议见 [客户端资源分发](../api/12-客户端资源分发.md) 和 [固件与 OTA 升级](09-固件与OTA升级.md)。

## 7. 站点配置

站点配置 `/admin/settings` 包含：

- 系统信息：站点名称、简称、Logo、Favicon、语言、ICP。
- 接入点：发现服务时长参数、中心直连公网 UDP 地址、端口、地区、网络和优先级。
- APRS：服务器、端口、本机地址、本机端口、呼号、SSID、经纬度、海拔、日志。
- OpenAI：Base URL、API Key、模型/Engine。
- 通信设置：是否启用音频记录、保留天数、最小录制阈值、最大录制时长、批量上传间隔。
- SMTP：服务器地址、端口、SSL、发件人昵称、发件人邮箱、授权码。
- 注册设置：是否要求邮箱验证。
- 操作日志：按事件类型和关键字查询系统操作记录。
