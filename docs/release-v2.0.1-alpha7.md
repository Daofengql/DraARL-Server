# DraARL v2.0.1-alpha7

本站统一使用一个节点入口。管理员配置节点 ID、公网 IP／域名和 UDP 端口，设备只配置 HTTP API，通过 API 查询当前 UDP 地址；不再需要配置发布开关。

- 移除多边缘节点的运行时、管理页面、入口择优和归属索引。保留独立站间互联，原有边缘 YAML 选项忽略。
- 同设备加装或拆除 SA818 后，服务端按当前型号提供配置能力，保留另一模式的参数；过期配置表单返回 `409`，提示重载。
- 移除射频保护设置及发射时长、占空比限制。旧字段忽略，已使用的 TLV 编号保留；断网和音频结束时正常释放 PTT。
- 修复动态码绑定重试被限流及重复领取配置的问题：限流桶原子校验，返回重试等待时间；相同用户可幂等重试，已就绪配置保留至会话过期；前端保留输入并提示冷却时间。
- 修复发布打包脚本引用已删除边缘配置的问题，将设备能力切换、过期表单和动态码重试的 MySQL 回归加入 CI 集成测试。

数据库升级自动迁移旧节点配置，保留业务数据与站间互联会话。部署前按常规备份数据库和配置；使用旧节点设置的设备客户端需适配 HTTP API 返回的本站入口。

服务端提供 Linux AMD64／ARM64、Windows AMD64、macOS Intel／Apple Silicon 构建及对应 SHA-256 校验文件。Android 和 RFBox 的配套变更不包含在本服务端二进制中。
