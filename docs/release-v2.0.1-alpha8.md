# DraARL v2.0.1-alpha8

修复“我的群组”页面禁用群组后，该群组立即从列表消失、无法在原页面重新启用的问题。
自己创建的公开组和私有组禁用后继续显示状态与管理开关，可以直接重新启用。

群组管理列表额外查询当前用户自己创建的禁用群组，分页总数与列表同步。
设备和电台的频道选择继续仅返回启用的群组；其他用户创建的禁用群组仍不可见。
API 查询参数说明见[群组与互联](api/04-群组与互联.md)。

已在虚拟机真实 MySQL 中复现旧问题，并通过群组查询、分页、成员权限和电台路由回归。
前端 57 项测试、类型检查、lint 和生产构建通过。

更新服务端并刷新 Web 页面即可使用，无需手工修改数据库。
提供 Linux AMD64／ARM64、Windows AMD64、macOS Intel／Apple Silicon 安装包及对应 SHA-256 校验文件。
