# DraARL v2.0.1-alpha14

本版本修正 Release 调用部署工作流时的 Secrets 继承，启用包含数据库备份和迁移的生产自动更新。

- Release 发布五个平台安装包后，GitHub runner 下载对应 tag 的 Linux AMD64 安装包，经专用 SSH 传到生产机，两端校验 SHA256。
- 停止 DraARL 后备份应用数据库，新程序通过 `-migrate-only` 执行版本化迁移和幂等 schema 同步；成功后原子替换程序、启动服务，核对就绪状态与实际版本。
- 保留原配置和旧程序，数据库备份仅 root 可读，成功升级后保留最近三份。重复部署相同且健康的程序不重复迁移和重启。
- 备份失败恢复旧服务；迁移开始后的失败保留数据库备份和日志、保持停服，并阻止后续自动部署，等待核对数据库及程序状态。

迁移版本仍为 5，设备协议保持兼容。发布前已通过迁移模块 Go 测试、8 项隔离部署测试、工作流语法检查和文档严格构建。
