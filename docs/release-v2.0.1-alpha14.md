# DraARL v2.0.1-alpha14

本版本修正 Release 调用部署工作流时的 Secrets 继承，启用数据库迁移的生产自动更新。

- Release 发布五个平台安装包后，GitHub runner 下载对应 tag 的 Linux AMD64 安装包，经专用 SSH 传到生产机，两端校验 SHA256。
- 停止 DraARL 后，新程序通过 `-migrate-only` 执行版本化迁移和幂等 schema 同步；成功后原子替换程序、启动服务，核对就绪状态与实际版本。数据库备份由宝塔定时任务负责，部署期间不额外导出 SQL。
- 保留原配置和旧程序。重复部署相同且健康的程序不重复迁移和重启。
- 迁移开始后的失败保留旧程序和日志、保持停服，并阻止后续自动部署，等待核对数据库及程序状态；需要恢复数据库时使用宝塔备份。

迁移版本仍为 5，设备协议保持兼容。发布前已通过迁移模块 Go 测试、8 项隔离部署测试、工作流语法检查和文档严格构建。
