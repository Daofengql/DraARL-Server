# DraARL v2.0.1-alpha10

站点 Logo 支持亮、暗主题分别上传和预览，随页面主题自动切换；未配置暗色图片时沿用亮色图片。图片预览失败时保留已保存配置，并支持重试。

仅 Logo 和 Favicon 通过服务端 `/logo.png`、`/logo-dark.png`、`/favicon.ico` 路由读取 S3，无需浏览器签名地址；兼容旧 Logo/Favicon 对象引用。其他资源沿用原有存储访问方式。修复保存系统信息时可能清空 Favicon 的问题。

删除备案图标并保留备案文字链接。修复 APRS 经纬度、海拔和定位按钮在不同窗口宽度下错位的问题。

录音按实际 Opus 包时长计算最小阈值、最大分段时长和记录时长，兼容不同帧时长与合并包。修复配置缓存失效分类，并校验最小阈值不能超过非零最大时长；关闭录音后清理未结束片段。

本地前后端测试、静态检查和构建通过；Hyper-V Ubuntu 上真实 MySQL/S3 集成测试及竞态检查通过，浏览器验证覆盖 320–1920 像素宽度。详细结果见 [站点设置验证记录](site-settings-validation-2026-11-12.md)。

更新服务端并刷新 Web 页面即可使用，无需手工修改数据库。提供 Linux AMD64／ARM64、Windows AMD64、macOS Intel／Apple Silicon 安装包及对应 SHA-256 校验文件。
