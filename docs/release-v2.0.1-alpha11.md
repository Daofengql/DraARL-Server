# DraARL v2.0.1-alpha11

本版本包含音频链路稳定性和在线设备显示修复，并补充了服务端运行时取证能力。

- WebSocket 写队列改为有界队列：队列满时保留控制帧、淘汰最旧语音帧；排队超过 500ms 的语音帧在写出前丢弃并计入 `writes_stale`。
- 修复在线设备列表的运行时稳定 key，避免同一用户的多个 UDP、幽灵或 WebSocket 会话互相覆盖。
- 增加 UDP 端点拒绝、禁发和半双工丢弃的按设备统计，并在管理员 UDP 指标接口提供查询结果。
- 网页端改进重连代际保护、后台恢复、设备列表请求取消，以及语音播放缓冲和积压淘汰。

本版本保持 DraARLv1 UDP 报文格式和 RF1、Android 的现有收发协议兼容。服务重启会让已有连接短暂重连，客户端无需同步升级即可恢复。

发布前已通过 Server Go 单测、race、vet、网页检查和本地构建验证；硬件板卡、Android 真机和生产部署机验证仍按实施记录中的边界执行。
