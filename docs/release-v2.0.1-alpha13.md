# DraARL v2.0.1-alpha13

本版本增加 Release 后的 Supervisor 自动部署，并将数据库备份和迁移纳入升级流程。

- 五个平台的安装包发布成功后，GitHub runner 下载本次 tag 的 Linux AMD64 安装包，通过专用 SSH 密钥传到生产机，两端校验 SHA256。
- 停止指定的 DraARL 服务后备份应用数据库，使用新程序的 `-migrate-only` 执行现有版本化迁移和幂等 schema 同步。迁移命令完成后退出，不启动网络服务、Redis 认证或后台任务。
- 迁移成功后原子替换程序，由 Supervisor 启动，再检查 `/readyz` 和实际版本。原配置保留，数据库备份仅 root 可读，成功升级后保留最近三份。
- 备份失败时恢复旧服务；迁移开始后的失败保留数据库备份、旧程序及迁移日志，保持停服并暂停后续自动部署，等待核对数据库状态，避免在部分迁移后盲目启动旧程序。
- 重复部署相同且健康的程序不重复备份、迁移或重启。不支持迁移入口的旧版本在停服前被拒绝。

本版本复用既有迁移引擎，迁移版本仍为 5；没有修改设备收发协议，既有 BoxV1、Box32 和 Android 客户端可继续使用。

发布前已通过迁移模块 Go 测试、8 项隔离部署测试、工作流语法检查和文档严格构建。隔离部署测试覆盖成功升级、重复部署、备份失败、部分迁移失败、就绪失败及安装包校验失败。
